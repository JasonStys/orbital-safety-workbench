# Version 1.1.0 — Orbital Safety Workbench

By Jason Stys. This prepared portable release includes illustrative sampled distance windows, exact interval bounds, censoring flags and replay inspection for civilian histories.

Windows ZIP and Linux/macOS tar.gz preserve each platform's required executable modes and relative native-library links. Archive names include product version, OS and CPU; embedded and adjacent `RELEASE.json` bind the product and source. Old 1.0.0 downloads remain historical and unchanged. No installer, user-data migration or production service is introduced.

Release automation accepts only new, exact-source drafts after complete main-push validation. It verifies the actual extracted executable, real compiled UI and practical export before writing the checksum. All three target OS jobs and six public asset digests require coordinator review before publication. See [release procedure](../RELEASE.md) and [recorded local validation](../reports/PORTABLE_REFRESH_20261109.md).

Historical ISS TLE/OMM replay and fictional sampled tracks only, with no real-time catalog, covariance, collision probability, targeting or maneuver guidance. Distances are illustrative display thresholds rather than operational safety radii.
